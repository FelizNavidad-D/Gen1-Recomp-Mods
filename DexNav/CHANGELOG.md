# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.2.0] - 2026-08-02

### Added

- **Remappable search trigger**: the button that spawns the registered POKéMON's encounter is now configurable via a new **DEXNAV TRIGGER** row in OPTIONS (default SELECT; cycles SELECT → START → A → B). The registration confirmation now names the currently mapped trigger.

### Fixed

- Registration confirmation used the old hard-coded "SELECT" label even after a remap.

## [1.1.0] - 2026-07-28

- Initial DexNav 1.1.0 release: encounter grid, register-to-trigger search, native target spawner, transition safeguards.

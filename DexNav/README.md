# DexNav

Hunt registered POKéMON on the overworld with a Gen 6-style DexNav grid, and remap the trigger button that launches the search.

## Try it

1. Install the mod (folder or zip), then open the START menu and pick **DEXNAV** to view the encounter grid for the current map.
2. Highlight a seen POKéMON and choose **REGISTER** — the default trigger for searching it is **SELECT** (the game confirms the current trigger when you register).
3. Press the trigger out on any map where the species can appear to spawn it; walk into the sparkling target to start a battle.
4. To rebind the trigger, open **OPTIONS** in the START menu and cycle the **DEXNAV TRIGGER** row between SELECT / START / A / B. To remap the physical key or controller button behind it (e.g. bind R shoulder to the trigger), use the engine's **CONTROLS** menu — this mod's trigger follows your CONTROLS bindings for whichever button you pick.

When the trigger is A or B, that button is consumed by the search while a POKéMON is registered, so interacting with the world moves to the other button until you unregister or clear the target.

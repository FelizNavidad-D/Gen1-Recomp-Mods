# Translucent UI

Makes UI boxes translucent so the world shows through, without breaking SGB colourization.

## Try it

1. Install the mod (folder or zip), then open any menu — boxes and full-screen fills render at 85% alpha outside battle.
2. Battles stay opaque so the SGB battle shaders and sprites are never corrupted.
3. Widescreen layouts (Voxel Mod) keep native full-width fills.

## Compatibility

- Works with the engine's native SGB zone pass: sprites keep their colours (party icons, HP bars, battle pics).
- No changes to Controls, Options, or saved options.
